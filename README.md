# ARCA official app downloads

This repository distributes signed ARCA application binaries. It does not contain application source code.

Download the latest Mac app from [Releases](https://github.com/METHEZONE/arca-releases/releases/latest).

- `ARCA-mac.dmg`: signed and notarized Apple silicon Mac installer.
- `ARCA-mac-arm64.zip`: the same signed Mac app in a ZIP archive.

The Mac app requires macOS 15 or later. iPhone and Apple Watch availability is managed through Apple's TestFlight/App Store distribution.
